# הדגמת ההצפנה (שלב 14 במסמך 05)

המטרה: צילום מסך אחד שבו רואים זה לצד זה את השורה במסד הנתונים, שבה `encryptedContent` הוא מחרוזת Base64 בלתי קריאה, ואת אותה רשומה במסך הפרטים, שבו התוכן קריא.

1. צרי רשומה (מהקליינט או מ-Swagger) עם תוכן מזוהה, למשל `מספר החשבון הוא 12-345-6789`. העתיקי את ה-`id`.
2. הריצי מול המסד (בממשק ה-SQL של ספק המסד, או ב-`npx prisma studio`):
   ```sql
   SELECT id, title, "encryptedContent", nonce
   FROM cipher_records
   WHERE id = '<ה-id שהעתקת>';
   ```
   העמודה `encryptedContent` תציג מחרוזת Base64 ארוכה, בלי זכר לטקסט המקורי.
3. פתחי את אותה רשומה במסך הפרטים בקליינט, כשאת מחוברת כשולחת או כנמענת. התוכן יוצג קריא.
4. צלמי את שני החלונות זה לצד זה.

מה להסביר בעל פה: המסד מחזיק ciphertext בלבד, המפתח נמצא במשתנה הסביבה `ENCRYPTION_KEY` בשרת, והשרת מפענח רק אחרי שהחליט שהפונה הוא השולח או הנמען. מכאן שדליפת המסד אינה חושפת תוכן, אבל מי שיש לו גישה לשרת כן יכול לקרוא אותו.

הבדיקה האוטומטית המקבילה נמצאת ב-`tests/records.test.ts`, בבדיקה "שליפה ישירה מהמסד מראה ש-encryptedContent אינו מכיל את הטקסט הגלוי".
